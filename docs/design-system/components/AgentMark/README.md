# AgentMark

نشانهٔ هر چیزی که مدل زبانی نوشته؛ مرز میان «محاسبه‌شده» و «نوشتهٔ عامل».

- `hr-agent` (زمینهٔ `steel`، متن `navy`، ستارهٔ ✦): امضای پیام‌های دستیار در گفت‌وگو. `hr-agent-dark` (`navy`): برچسب داخل قاب توضیح.
- `hr-agent-note`: قاب کامل با زمینهٔ `steel-wash` و **مرز نقطه‌چین** `navy`. نقطه‌چین یعنی «هنوز تأیید انسانی نشده»؛ هیچ قاب دیگری نقطه‌چین نیست.
- عدد محاسبه‌شده هرگز داخل این قاب نمی‌آید؛ عدد در `figure` و جدول است.
