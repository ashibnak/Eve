# Badge

برچسب وضعیت یک یا دو کلمه‌ای؛ همیشه با قاب ۲ پیکسلی و گوشهٔ تیز.

- `hr-badge-wait` (کرم): منتظر اقدام شما. `hr-badge-block` (قرمز توپر با مربع): قاعدهٔ مسدودکننده. `hr-badge-warn` (متن و قاب `red-dark` با «!»): هشدار. `hr-badge-ok` (سبز با تیک): در محدودهٔ مجاز. `hr-badge-info` (`steel`): اطلاع. بدون پسوند: خنثی.
- هر وضعیت علاوه بر رنگ یک نشانه دارد (■، !، ✓) و همیشه متن دارد.
- مصرف‌کننده فقط متن را می‌دهد. برای نوشتهٔ عامل از AgentMark استفاده کنید.
