# Button

دکمه برای انجام یک کار؛ متن آن فعل است و دقیقاً می‌گوید چه می‌شود.

- `hr-btn` (پیش‌فرض): سفید با مرز ۲ پیکسلی `navy`، ارتفاع ۴۴.
- `hr-btn-primary`: زمینهٔ `red`، متن `on-red`، سایهٔ سخت `shadow-hard-sm`؛ با فشردن، سایه حذف و دکمه به جای سایه می‌نشیند. **فقط یکی در هر نما.**
- `hr-btn-dark`: زمینهٔ `navy` برای کار مهم ولی غیرتصمیمی (خروجی گرفتن).
- `hr-btn-ghost`: بدون قاب، متن `red-dark`؛ فقط برای «رد» و کارهای منفی کم‌تکرار.
- `hr-btn-sm` (۳۲ پیکسل): پیشنهادهای گفت‌وگو و کار درون ردیف.
- متن: فعل امری یک تا سه کلمه‌ای. دکمه را غیرفعال نکنید؛ با کلیک بگویید چه کم است.
