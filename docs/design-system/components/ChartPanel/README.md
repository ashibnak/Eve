# ChartPanel

قاب یک نمودار در گزارش‌ها: عنوانِ نتیجه، زیرعنوانِ تعریف، و خود نمودار.

- `hr-chart` با قاب ۲ پیکسلی `navy` و بدون سایه. عنوان (`heading`) **نتیجه را می‌گوید** («فین‌تک تنها بخش زیر هدف است»)، نه نام موضوع. زیرعنوان می‌گوید چه چیزی با چه واحدی و مرز هدف کجاست.
- رنگ نمودار: داده‌های عادی `navy`، دستهٔ دوم `steel`، مقدار مشکل‌دار یا آخرین نقطه `red` با برچسب `red-dark`. خط هدف نقطه‌چین `red`. خطوط راهنما `grid`. نقطه‌های خط‌نمودار مربع‌اند.
- میله‌ای افقی برای مقایسهٔ واحدها، خطی برای روند ماهانه، ستونی برای توزیع. هر نمودار به یک مقیاس رسم می‌شود و عدد هر میله کنارش نوشته می‌شود.
- پیاده‌سازی: `Recharts` با همین توکن‌ها. مثال کامل در `hr-bars` همین پیش‌نمایش.
