# ChatMessage

پیام‌های گفت‌وگو با دستیار در وب؛ همان الگو در بله به متن و دکمه تبدیل می‌شود.

- پیام کاربر `hr-msg-user`: بلوک `navy` با متن کرم، سمت شروع (راست).
- پاسخ دستیار `hr-msg-agent`: بدون حباب، سمت پایان. سر پیام: `hr-agent` و فهرست منابعی که خوانده شد (`hr-msg-sources`). عدد و پیشنهاد در `hr-msg-card` با سایهٔ سخت، با دکمه‌ای که آن را به تصمیم رسمی تبدیل می‌کند.
- پای هر پیشنهاد (`hr-msg-foot`) می‌گوید تا تأیید چیزی تغییر نمی‌کند.
- جعبهٔ نوشتن `hr-composer` با سایهٔ سخت و دکمهٔ ارسال `red`. پیشنهادهای آماده با `hr-btn-sm` بالای آن.
