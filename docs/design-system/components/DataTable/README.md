# DataTable

جدول فشردهٔ کارشناس؛ پرکاربردترین نمای محصول.

- `hr-table-wrap` > `table.hr-table`. سرستون با زمینهٔ `navy` و متن `cream-on-navy`؛ ردیف‌ها با خط ۲ پیکسلی `navy` جدا می‌شوند. hover با `surface-cream`.
- ستون عددی `hr-num`: ارقام هم‌عرض و جداکنندهٔ هزارگان؛ واحد در سرستون. مقدار مشکل‌دار با `hr-bad` (`red-dark` پررنگ).
- کار هر ردیف یک پیوند فعل در ستون آخر («اصلاح»، «بررسی»).
