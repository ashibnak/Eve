# DecisionCard

نمای استاندارد هر یک از ۱۸ تصمیم؛ الگوی امضای محصول.

ترتیب ثابت، از بالا به پایین:

1. **سر:** برچسب تصمیم با `red-dark` (eyebrow)، موضوع با سبک `title`، و Badge وضعیت.
2. **عدد اصلی:** `figure-xl` (۴۶ پیکسل، وزن ۹۰۰)، واحد، و تغییر در نشان `steel`.
3. **PayBandBar** برای تصمیم‌های حقوقی.
4. **ورودی‌ها:** شبکهٔ دوستونی با خطوط ۲ پیکسلی؛ هر ورودی با منبع کلیک‌پذیر.
5. **کنترل قواعد:** ✓ سبز یا ! قرمز تیره.
6. **توضیح عامل:** فقط داخل `hr-agent-note`.
7. **پا:** VersionTagها و سه دکمه: «رد» (ghost)، «برگرداندن»، «تأیید» (primary).

- کارت قاب ۲ پیکسلی و `shadow-hard-lg` دارد؛ تنها کارت صفحه با بزرگ‌ترین سایه.
- مصرف‌کننده سند تصمیم را می‌دهد؛ کارت چیزی محاسبه نمی‌کند.
