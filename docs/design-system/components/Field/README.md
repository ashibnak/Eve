# Field

ورودی با برچسب بالای آن و یک خط راهنما یا خطا زیرش.

- ساختار: `hr-field` > `hr-label` + `hr-input` + `hr-help`. ورودی ۴۴ پیکسل، قاب ۲ پیکسلی `navy`، گوشهٔ تیز.
- خطا: `hr-field-error`؛ قاب `red` و پیام پررنگ `red-dark` که می‌گوید چه باید کرد.
- placeholder نمونهٔ واقعی است. تاریخ شمسی نمایش، میلادی ذخیره. مبلغ به ریال با «٬».
