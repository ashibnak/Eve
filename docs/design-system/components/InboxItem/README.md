# InboxItem

یک ردیف صندوق کار؛ صفحهٔ اول هر کاربر فهرستی از همین ردیف‌هاست.

- `hr-inbox` > `hr-inbox-row`: عنوان (`body-strong`) و یک خط فراداده. ردیف انتخاب‌شده `is-selected` تمام `navy` می‌شود.
- هشدار با `is-warn` و مربع ■؛ نوشتهٔ عامل با ✦ در فراداده.
- ترتیب: مسدودکننده، منتظر شما، هشدار، بقیه؛ در هر گروه قدیمی‌ترین اول.
