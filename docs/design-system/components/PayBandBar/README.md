# PayBandBar

جای حقوق یک نفر در باند رتبه‌اش، فعلی و پیشنهادی، در یک نگاه.

- ریل `steel-soft` با قاب `navy`؛ میانه خط عمودی `navy`. فعلی: مربع سفید. پیشنهادی: مربع `red`. تفاوت با رنگ و پر/خالی دیده می‌شود.
- مصرف‌کننده کمینه، میانه، بیشینه، فعلی، پیشنهادی و واحد را می‌دهد. موقعیت = (مقدار − کمینه) ÷ (بیشینه − کمینه) با `inset-inline-start`؛ کمینه سمت راست.
- خط راهنما زیر نوار همیشه هر دو عدد و نسبت مقایسه را می‌نویسد.
