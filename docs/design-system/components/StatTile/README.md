# StatTile

کاشی یک عدد خلاصه بالای صفحه؛ سه یا چهار تا در یک ردیف.

- `hr-stat` با قاب ۲ پیکسلی و `shadow-hard`؛ برچسب `label`، عدد `figure-lg`، یک خط توضیح اختیاری.
- فقط **یک** کاشی در ردیف `hr-stat-hot` (زمینهٔ `red`) می‌شود: همان که کاربر باید الان رویش کار کند.
- عدد مشکل‌دار در کاشی عادی با رنگ `red-dark`.
